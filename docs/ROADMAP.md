# Predi AI Roadmap (Planning)

This roadmap is a planning artifact only. It is not a commitment to ship dates.

## Now -> 90 Days (Moat: Continuity + Speed)
- Continuity-first long video: make Reference Kit default for long video, add auto continuity report.
- Brand memory upgrades: enforce brand do-not-change rules on every generation.
- Showcase curation tools: admin tagging, categories, and spotlight collections.
- Multi-asset QA checks: detect visual drift, missing products, or style breaks.
- Public asset share links with lightweight analytics.

## 3 -> 6 Months (Moat: Performance + Feedback Loops)
- Auto A/B variants with simple winner selection.
- Platform personas (TikTok/IG/LinkedIn) for tone + pacing differences.
- Performance grounded iterations (connect ads data to new variants).
- Creator workflows: templates, campaign packs, and editorial calendars.
- Brand health dashboard: drift alerts, quality score, and asset reuse stats.

## 6 -> 12 Months (Moat: Data + Network Effects)
- Product feed integrations (Shopify/WooCommerce) for dynamic creatives.
- Vertical-specific playbooks and prompt libraries.
- Creator marketplace for AI-to-human collaboration.
- Localization engine with regional visual cues.
- Governance/Compliance agent (claims, category rules).

## Moat Drivers
- Continuity: avatar + product reference system across scenes.
- Speed: agentic pipeline with structured prompts and guardrails.
- Data: closed-loop performance training via analytics connectors.
- Trust: clear ROI/cost visibility and consistent quality controls.

## Success Metrics (North Stars)
- Time-to-campaign (brief -> assets).
- % assets reused or re-shipped.
- Long-video approval rate.
- Revenue-per-active-board.
- Organic search traffic for "AI marketing" intent queries.
